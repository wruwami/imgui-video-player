# UI 와이어프레임 (Wireframes)

> 화면 구성의 기준선. 새 패널/기능 추가 전에 이 문서에 와이어프레임과
> 동작 명세를 먼저 추가한다. `[M*]` 태그는 구현 마일스톤 (docs/architecture.md §8).

### 영역 명세 (M1)

| 영역 | 요소 | 동작 |
|---|---|---|
| 입력 행 | 경로/URL 입력 + `Open` | 파일/RTSP/DASH URL 입력 → Enter 또는 Open → 채널 생성 ( busy 시 비활성 ) |
| | `Close` | 채널 정지·해제 (워커 조인, 큐 클리어) |
| | `Recent` | 최근 열람 목록(최대 8개), 선택 시 즉시 재생 |
| VIDEO AREA | 레터박스 뷰 | 종횡비 유지 중앙 배치, 여백은 검정. 창 크기 변경에 실시간 추적 |
| | HUD (좌상단 오버레이) | `WxH · fps · 코덱 (디코더경로) · 상태` — 예: `1280x720 29.9fps h264 (d3d11va) playing`. 오류 시 빨강 한 줄 추가 |
| 컨트롤 행 | Play/Pause | 파일: 토글. Ended 상태에선 `Play` = 처음부터 |
| | 시크바 | 파일 소스만. 초 단위 슬라이더, 드래그 중에도 위치 표시 |
| | 배속 | 파일 소스만. 0.25/0.5/1.0/2.0/4.0 |
| Monitors 패널 | 모니터 트리 | 이름/해상도/주사율/위치/작업영역/물리크기/DPI — M4 wall 모드의 선택 근거 |

전역 입력: **파일 드래그앤드롭** → 창 위로 드롭하면 (재생 중이 아니면) 즉시 재생.
CLI: `imgui-video-player.exe <경로|URL>` — 시작 즉시 재생.

### M2 추가 명세

| 요소 | 동작 |
|---|---|
| Channels 패널 | 채널 목록(이름/URL/상태/디코더 경로). 추가=URL 입력, 제거=선택+버튼. 상태 색: ●재생(녹) ○정지(회) ↻재접속(노) ✕오류(빨) |
| 그리드 프리셋 | 툴바 버튼으로 셀 수 전환. 채널↔뷰 바인딩은 유지됨(셀 수 줄이면 숨김, 늘리면 복원) |
| 빈 셀 | 점선 테두리 + `드래그하여 채널 배치` 안내 |
| 셀 HUD | 셀 좌상단 작은 오버레이(1행), 마우스 오버 시 확장판(2행: 큐 적체/드롭/재접속 횟수) |
| 채널 바인딩 | 브라우저 항목을 셀로 드래그 → 바인딩. 셀끼리 드래그 → 스왑. 더블클릭 → 해당 셀 1x1 포커스 |

## 3. wall 모드 (M4, 멀티 모니터)

```
   메인 모니터 (편집)                        보조 모니터 (전용 출력)
┌───────────────────────────┐          ┌───────────────────────────────┐
│ imgui-video-player        │          │ ┌─────────┬─────────┬────────┐│
│  ... 일반 UI 그대로 ...      │   드래그  │ │ CAM-01  │ CAM-02  │ CAM-03 ││
│                           │  ──────▶ │ ├─────────┼─────────┼────────┤│
│ [Wall: LG 27GP850 ▾] [ON] │          │ │ CAM-04  │ CAM-05  │        ││
│  모니터 선택 → 전용 뷰포트    │          │ └─────────┴─────────┴────────┘│
│  전체화면, UI 없음, ESC 복귀 │          │  (OS 커서만 존재, 테두리/타이틀 없음) │
└───────────────────────────┘          └───────────────────────────────┘
```

- wall 뷰는 메인 UI와 독립된 ImGui 뷰포트 = 모니터 전체. 채널 배치는 메인의 그리드 상태를 따름.
- ON 토글/ESC로 복귀. 창 모드 해제 시 기존 DockSpace 그대로 복원.

## 4. 상태/표기 규칙 (전체 공통)

| 상태 | 표기 | 비고 |
|---|---|---|
| Opening | `opening...` | 소스 프로브 중 |
| Playing | `playing` | 정상 |
| Paused | `paused` | |
| Reconnecting | `reconnecting #N` | RTSP 재접속 중, N=시도 횟수 (M3) |
| Ended | `ended` | 파일 EOF |
| Error | `error` + 사유 1행 | 빨간색 |

- 디코더 경로 표기: `(d3d11va)` / `(videotoolbox)` / `(vaapi)` / `(sw)` — 사용자가 HW 가속 여부를 항상 알 수 있어야 함 (프로젝트 목표 1).
- 지연 지표(M3): 큐 적체, 프레임 드롭 누적, 파이프라인 지연(ms) — 오버레이 확장판에만 표시(기본 비표시로 화면 오염 방지).

## 5. 변경 절차

1. 이 문서에 와이어프레임 추가/수정 → PR 설명에 스크린샷 또는 다이어그램 첨부.
2. 구현 PR은 이 문서의 해당 영역 명세를 충족해야 하며, 어긋나면 문서 또는 코드 중 하나를 같은 PR에서 정렬.
